# @greenart/mobile — Customer Mobile Application

Native customer mobile application for **Greenart Properties: Land Market Rate Analyst**.

## Technology Stack
- **Framework:** React Native
- **Runtime & Tooling:** Expo SDK 51, TypeScript
- **Mapping:** `react-native-maps` / Leaflet web fallback
- **Target OS:** Android & iOS

## Running Locally
```bash
npm install   # When dependencies are installed
npx expo start
```
- Press `a` to open Android Emulator / connected device.
- Press `i` to open iOS Simulator.
- Press `w` to open web preview.
