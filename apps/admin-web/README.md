# @greenart/admin-web — Back-Office Administration Portal

The administrative single-page application (SPA) for **Greenart Properties: Land Market Rate Analyst**.

## Technology Stack
- **Framework:** React 18
- **Tooling:** Vite 5, TypeScript 5
- **Mapping:** Leaflet & React-Leaflet
- **Styling:** CSS variables design system

## Setup & Running Locally
```bash
npm install   # When dependencies are formally installed
npm run dev
```

The application runs on `http://localhost:5173`.
All communications are routed via the backend API at `http://localhost:5000/api/v1/admin`.
Direct database connections are strictly prohibited.
